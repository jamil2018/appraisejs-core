# Slice 08: Planner Evals, Certification, And Release

Certify both lifecycle integrity and host-agent planning quality. Add rubric-based fixtures for ambiguous,
contradictory, stateful, security-sensitive, accessibility-relevant, and data-sensitive requirements.

Acceptance:

- Planner evaluation scores provenance, query usefulness, risk discovery, obligation quality, scenario diversity,
  falsifiability, redundancy, assurance, attribution, and interaction efficiency.
- Adversarial fixtures prove broken validations cannot become product defects.
- `certify:quality-os` emits a content-addressed receipt and is a release gate.
- MCP fixtures, coordinator reference, active docs, scaffold, Graphify, package builds, root build, static analysis,
  and fresh end-to-end lifecycle certification pass.
