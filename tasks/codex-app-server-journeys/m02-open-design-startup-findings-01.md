## Concrete hints

1. **Notification compatibility.** Open Design's [session test](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/tests/codex-app-server-session.test.ts#L506) explicitly permits an unfamiliar notification without failing the run. Its [normalizer](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/src/agent-protocol/codex-app-server/normalize.ts#L701) counts unrecognized notifications. R5 `protocol.mjs` instead fences every unclassified notification. The current generated Codex schema defines `mcpServer/startupStatus/updated`, but R5 has no classifier for it.
2. **Startup ordering.** The pinned [session](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/src/agent-protocol/codex-app-server/session.ts#L456) writes `initialized` and immediately requests `thread/start` in the initialize-response callback. Its tests assert both appear after that response. R5 marks ready, then the runner's separate 20 ms polling loop sends `thread/start`. That leaves a window for a startup notification or transport event to fence R5 before any thread reservation. R5 serializes incoming feeds; no feed-reentrancy bug was established. Required MCP startup verification runs after the thread-start response, so it is not a demonstrated cause of the missing thread-start send.
3. **Shutdown proof.** Open Design closes stdin when the turn ends and observes the actual child's close before issuing closed-thread cleanup authority. R5's ambiguous-stop receipt records a SIGTERM request/listener closure and explicitly does not prove process exit. This reinforces the recorded cleanup limit; it does not prove stdin EOF alone would close this newer binary or authorize cleanup of UNKNOWN history.

Open Design includes `jsonrpc: "2.0"` and empty notification params. R5's `initialized` envelope omits both, but the current generated ClientNotification schema permits method alone. Envelope omission is not a proven defect or cause.
