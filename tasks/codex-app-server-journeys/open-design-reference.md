## Adaptation rules

1. **Keep Codex as the agent engine.** Appraise composes role instructions and supplies scoped MCP tools; Codex owns its model/tool loop. Begin with Codex only. Do not add a generic multi-agent registry or a second model loop merely because the reference supports them.
2. **Separate durable session identity from authority.** Bind provider thread/turn IDs to Appraise's Journey, project, generation, WorkAttempt and input revision. A provider handle cannot replace a valid lease or authorize resumed work. The upstream session captures resume responses as well as new-thread notifications; cover both paths in M03 tests.
3. **Make process lifetime an explicit M05 decision.** Compare a supervised per-turn child plus native resume with a persistent supervised child. Record startup cost, MCP setup, interruption, cleanup and crash behavior. Both options must satisfy M04 durable intent and M11 unknown-outcome reconciliation. No automatic resend after a lost start acknowledgement.
4. **Normalize presentation without creating another state authority.** Provider events may update activity indicators. Only canonical accepted submissions and explicit human decisions advance the Journey. A completed turn without an accepted artifact must remain incomplete or recovery-required. Do not map Open Design's `completedSuccessfully()` directly to Journey success.
5. **Preserve the no-chat UI.** Structured questions become Appraise forms, and committed answers trigger eligible work. Never copy chat transcripts, reasoning streams, shell output or file diffs into the normal Journey UI. Preserve review pinning, operational/revision freshness and pending edits. Polling remains the initial transport; SSE is optional and requires scoped access, cursor recovery, bounded payloads, keepalives and polling fallback.
6. **Treat permissions as a separate qualification.** Open Design documents trusted CLI execution with workspace writes and broader access in some configurations. Its session sets a noninteractive approval policy. Neither is proof of scoped MCP-only authority. M02 must independently verify tool allowlists, required MCP startup, denied direct database/source/credential access and rejection of human-decision calls. Do not copy permissive defaults or ambient configuration.
7. **Handle protocol evolution deliberately.** Optional presentation notifications can be ignored with bounded diagnostics. Unexpected requests and missing required capabilities must block safely. Determine features from the actual launched binary/handshake; upstream preview-version thresholds are not Appraise's supported-version policy. Do not automatically fall back to another transport after an ambiguous run.

## Test references and Appraise acceptance additions

The upstream guide names these verified paths. Read the tests before adapting their fixtures; their existence is not a passing test result in this review:

- [Session tests](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/tests/codex-app-server-session.test.ts) and [protocol contract tests](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/tests/codex-app-server-protocol-contract.test.ts) → M01/M05: framing, request correlation, start/resume, rejected requests, malformed responses and interruption.
- [Normalizer tests](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/tests/codex-app-server-normalize.test.ts) and [transport parity tests](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/tests/codex-app-server-parity.test.ts) → M05/M07: stable event identity, duplicate/late events, payload filtering and canonical state remaining unchanged by presentation events.
- [Transport selection tests](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/tests/codex-app-server-transport-switch.test.ts) → M01/M12: explicit selection and capability failures; no silent dual-host fallback.
- [Patch preview tests](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/tests/codex-app-server-patch-stream.test.ts) and [command output tests](https://github.com/nexu-io/open-design/blob/014bffbf775f4514020cef8bbffdc0eb5a0009ce/apps/daemon/tests/codex-app-server-command-output-stream.test.ts) → optional event-ordering/bounds references only. They do not add file editing or raw-output streaming to Appraise's scope.

Appraise-specific verification remains mandatory: lost start/submission acknowledgements, duplicate wakes, concurrent supervisors, stale generations, revoked grants, canonical acceptance after interruption, required human gates and zero model turns during human waits. A clean provider exit or an upstream fixture does not qualify these invariants.
