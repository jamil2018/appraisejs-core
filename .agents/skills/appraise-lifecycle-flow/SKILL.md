# Appraise Lifecycle Flow

Use this skill for requirements, Quality Plan revisions, validation design, Assessments, evidence review, decisions, stop, or recovery work.

1. Read `docs/agent-lifecycle-flow.md` and `docs/coordinator-api-mcp.md`.
2. Treat requirement approval, validation-design approval/publication, Assessment evidence review, and AssessmentDecision as
   Appraise-owned gates.
3. Do not substitute chat approval for requirement approval, validation publication, evidence review, or a quality decision.
4. Read requirement queries, validation feedback, and evidence limitations before revising or deciding.
5. Reconcile managed Assessment executions until evidence is sealed before requesting a decision.
6. Report whether evidence came from browser/UI approval, service/API approval, MCP tools, or backend tests.
