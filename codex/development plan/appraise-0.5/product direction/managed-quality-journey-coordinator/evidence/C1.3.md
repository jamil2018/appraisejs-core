# C1.3 — Later-stage reconnect and takeover evidence

Status: `verified` on 2026-09-13 after independent exact-artifact review. GC1 was not evaluated.

## Delivered behavior

C1.3 extends the prepared Codex handoff to every mutable Journey stage without granting graph or role authority. Each
handoff captures the exact target reference, Journey state, active revisions, work/attempt/effect state, pending-event
sequence and a monotonically increasing Journey/target coordinator generation. Stock Codex has no qualified
known-task reopen contract, so a recorded, archived, missing or otherwise unavailable task truthfully falls back to a
fresh scoped `codex://new` handoff; Appraise never infers host-task liveness.

Redemption remains connection evidence only. A separate expiring, request-bound, UI-only approval is required before
takeover. Approval re-reads the authoritative snapshot, rejects a non-latest generation, reconciles active and
ambiguous effects, fences the predecessor session and active attempt, preserves the remaining immutable attempt
budget, makes eligible replacement work reclaimable, and persists an idempotent result for lost-reply recovery.
Every coordinator-owned Journey mutation, including specialized lifecycle ingress and Journey-scoped locator writes,
rechecks the current handoff/generation inside its write transaction. Stale target, revision, event, lease, assignment
generation, secret, approval or coordinator generation fails before mutation.

Canonical implementation includes:

- `prisma/schema.prisma` and migration `20260913090000_add_coordinator_handoff_reconnect_takeover`;
- `src/services/coordinator/quality-journey-handoff-service.ts`, Journey role services, query service, and
  `locator-ensure-service.ts`;
- internal coordinator routes, handoff server actions, Journey panel and presentation;
- package MCP schemas/fixtures and the generated coordinator operation reference; and
- the synchronized `packages/create-appraisejs/templates/base` projection.

No C2 role execution or submission behavior was added.
