shows plugin/MCP commands. This is not a fresh installed desktop recognition test or model-captured schema proof.

not comprehensive physical-schema drift detection. Revocation blocks new mediated admissions after the credential
read; already admitted requests/owned execution need local pause and C3.1 reconciliation. No external Codex stop,
quota, model, sandbox, background wake or host cleanup attestation is inferred.
