## Implemented boundary

Durable records bind the route-derived `PROJECT_CREDENTIAL_ONLY` principal, target, Journey, role, graph work item, immutable input/authorization, assignment/generation, lease, secret verifier, and request/receipt hashes. Each role uses its existing canonical validator and artifact/transition service. Shared admission rechecks caller-held secret, target, Journey, role, work item, assignment, generation, lease, principal, Journey mutability, authorization, and `IN_PROGRESS` ownership. The canonical effect and durable receipt commit atomically. Exact authenticated replay returns the saved outcome; conflicting reuse fails without a second effect. `quality_journey_external_work_outcome_get_v1` reconciles a lost acknowledgement with the same binding.

The Coordinator error envelope returns bounded `read_state_then_retry` only for an ambiguous internal failure on one of the six external specialized ingress routes. It directs callers to the outcome-read tool with non-secret binding fields and requires the same caller-held secret. Validation, authorization, not-found, and state-conflict errors remain `not_started` / `do_not_retry`.
