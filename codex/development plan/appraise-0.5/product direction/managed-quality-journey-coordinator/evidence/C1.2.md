## Scope and verdict

C1.2 is verified under its prepared-launch boundary after independent exact-artifact review. The canonical launch path emits a validated
`codex://new` URL whose `path` and `prompt` query values are encoded with `URLSearchParams`. Local targets launch in
their own absolute workspace. Qualified remote targets launch in a neutral temporary host workspace while the prompt
retains the normalized remote URL as the Appraise target. The prompt contains only plugin guidance, the one-time
ticket, Journey identity, normalized target, and the explicit redemption/read and non-authority boundary; it does not
contain requirement content or broad credentials.

The UI reports `Launch requested` for both the launch-in-progress and launched-but-unredeemed states. It advances to
`Connection observed` only after its polling read observes Appraise's durable `CONNECTED` handoff. Launch failure
retains the already copied prompt as a manual fallback. Authenticated redemption remains one-time, expiring,
Journey/target-bound, and ticket-hash-backed. An incorrect project fingerprint now returns the bounded `409 CONFLICT`
project-identity envelope before any redemption effect instead of `500 INTERNAL/appraise_runtime_defect`.

This is connection evidence only. Plugin recognition, URI prefill, the user's Send action, authenticated redemption,
and the authoritative read did not authorize Journey work, claim an assignment, or transfer Appraise lifecycle
authority. C1.3 was not started and GC1 was not evaluated.
