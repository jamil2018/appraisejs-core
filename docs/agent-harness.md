# Agent Harness

The AppraiseJS harness coordinates repository engineering and validates the quality-management workflow without replacing Appraise-owned state transitions. Repository instructions, source, tests, and generated contracts are authoritative over historical task documents.

For meaningful engineering work, classify the task through the swarm router, record a compact route receipt, preserve unrelated worktree changes, and use deterministic validation before publication. The routing system governs agent work; the product workflow governs requirements, Quality Plans, validations, Assessments, evidence, and decisions.

An end-to-end quality audit uses the executable MCP contract: bind a target; read the versioned methodology; submit a requirement source; propose and review an exact Requirement Analysis; answer blocking queries; propose and review an exact Validation Design; mechanically realize and publish its Validation Versions; create an Assessment; approve its immutable execution manifest when policy requires it; run and reconcile evidence; record attributed obligation findings; and issue an exact decision. Chat agreement and static client configuration are not transition evidence.

Appraise supplies the reasoning pathway, schemas, rubrics, deterministic critiques, immutable review artifacts, and state gates. The host agent supplies semantic reasoning. This product quality harness is separate from the repository-development harness that tells coding agents how to change AppraiseJS itself.

The generated setup capability inventory, MCP contract fixture, coordinator operation reference, scaffold mirrors, and Graphify outputs must be refreshed from canonical source when their inputs change.
