# Agent Harness

The AppraiseJS harness coordinates repository engineering and validates the quality-management workflow without replacing Appraise-owned state transitions. Repository instructions, source, tests, and generated contracts are authoritative over historical task documents.

For meaningful engineering work, classify the task through the swarm router, record a compact route receipt, preserve unrelated worktree changes, and use deterministic validation before publication. The routing system governs repository work; Quality Journey governs agent-enabled quality analysis, scenarios, execution evidence, triage, decisions, and closure.

An end-to-end quality audit uses the executable Journey contract: bind a target; create a Journey; complete its analysis and scenario review gates; materialize exact runtime capsules; execute Journey-bound TestRuns; seal evidence; triage results; review reports and reruns; and close the Journey. Independent TestRuns remain non-authoritative diagnostics. Chat agreement and static client configuration are not transition evidence.

Appraise supplies the reasoning pathway, schemas, rubrics, deterministic critiques, immutable review artifacts, and state gates. The host agent supplies semantic reasoning. This product quality harness is separate from the repository-development harness that tells coding agents how to change AppraiseJS itself.

The generated setup capability inventory, MCP contract fixture, coordinator operation reference, scaffold mirrors, and Graphify outputs must be refreshed from canonical source when their inputs change.
