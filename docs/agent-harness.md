# Agent Harness

The AppraiseJS harness coordinates repository engineering and validates the quality-management workflow without replacing Appraise-owned state transitions. Repository instructions, source, tests, and generated contracts are authoritative over historical task documents.

For meaningful engineering work, classify the task through the swarm router, record a compact route receipt, preserve unrelated worktree changes, and use deterministic validation before publication. The routing system governs agent work; the product workflow governs requirements, Quality Plans, validations, Assessments, evidence, and decisions.

An end-to-end quality audit uses the executable MCP contract: bind a target, approve a requirement revision, approve a Quality Plan revision, publish a Validation Version, create and run an Assessment, reconcile evidence, and issue an exact decision. Chat agreement and static client configuration are not transition evidence.

The generated setup capability inventory, MCP contract fixture, coordinator operation reference, scaffold mirrors, and Graphify outputs must be refreshed from canonical source when their inputs change.
