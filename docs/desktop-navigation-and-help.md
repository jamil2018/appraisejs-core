# Desktop navigation and help

AppraiseJS keeps existing route URLs stable while presenting one human-facing name for reusable test-case structures: **Case Templates**. Source and database identifiers may retain `TemplateTestCase` for compatibility.

The command palette indexes Help under `help`, `setup`, `glossary`, `approvals`, and `recovery`. The Help page is explanatory only: viewing it does not create a record, connect an agent, approve a revision, or start work.

Settings is a workspace configuration overview. It links to the active project's implemented project, environment, and Codex setup controls. It does not imply native desktop preferences or filesystem synchronization authority.

The proposed navigation regrouping remains pending intended-user first-click evidence. Until that evidence exists, the current group placement is preserved to avoid a speculative information-architecture change.
