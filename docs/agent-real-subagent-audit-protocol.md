# Agent Quality Workflow Audit Protocol

An end-to-end audit records the actual MCP transport, target binding, executable capability inventory, requirement revision, Quality Plan revision, Validation Version, Assessment identity, managed TestRun identities, sealed Evidence Receipts, and final decision hash.

The audit must prove that the documented quality workflow completes without unavailable operations, compatibility guidance, or unbound target state. Preserve only bounded evidence needed to reproduce the observed contract and runtime results.
