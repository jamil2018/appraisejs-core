# Managed Validation Inventory

The quality lifecycle owns requirement revisions, Quality Plan revisions, published Validation Versions, Assessments, managed TestRuns, and sealed Evidence Receipts. Shared authored tests, Step Definitions, locators, environments, reports, and runtime capsules remain reusable infrastructure.

Validation publication binds a Quality Plan revision to immutable executable inputs. Assessment execution binds that publication to an evaluation-subject revision and matrix cell. Reconciliation then records receipt provenance for the exact capsule, TestRun, and execution artifacts consumed by review.

Generated projections, runtime capsule artifacts, and scaffold mirrors are derived from canonical source. Update their generator or source definitions and run the prescribed regeneration workflow; never patch generated outputs as a substitute for a source change.
