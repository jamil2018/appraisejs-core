# CLI Skills And Recovery

Use the workspace’s registered engineering skills for repository navigation, runtime validation, scaffold maintenance, Graphify, quality checks, and swarm routing. They do not create product state or replace AppraiseJS review decisions.

When a quality workflow call is unavailable, verify the active MCP transport, generated capability inventory, target binding, and current executable contract. Do not infer unavailable behavior from historical workflow documentation. Recover by reading the current Assessment or Quality Plan state and using only the next operation exposed by the contract.

For repository work, preserve unrelated changes, validate focused scopes first, and regenerate contract, scaffold, and graph artifacts from canonical sources when applicable.
