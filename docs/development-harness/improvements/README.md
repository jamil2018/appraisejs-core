# Development-harness improvement proposals

Each `proposal-*.md` file is a versioned advisory backlog record with validated YAML front matter. It embeds sanitized supporting evidence so references remain portable and checkable without the local journal. Proposal states are `proposed`, `deferred`, `accepted`, `implementing`, `evaluating`, `verified`, `rejected`, and `superseded`.

Only an `accepted` transition requires a host-conversation authority receipt. A proposal never blocks an unrelated feature from completing, and none of these records may change harness policy automatically.

Use `node scripts/harness-learning.mjs propose`, `list-proposals`, `show-proposal`, `transition-proposal`, and `evaluate` to maintain this backlog.
