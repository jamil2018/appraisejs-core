# Development-harness lessons

Each `lesson-*.md` file is a versioned advisory record with validated YAML front matter. It records its task and path applicability, embedded sanitized supporting and contradictory evidence, confidence, harness version, and validation time. The embedded evidence keeps the record usable in a fresh checkout without the local journal.

The records are portable repository evidence. They do not grant authority to alter agent roles, model selection, permissions, mandatory instructions, or quality gates.

Use `node scripts/harness-learning.mjs lessons` to retrieve a bounded contextual set and `revalidate-lesson` after fresh evidence.
