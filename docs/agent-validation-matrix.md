Use the narrowest check that can catch likely regressions, then broaden when the touched surface is shared, packaged,
or release-like.

Run Fallow and React Doctor through `npm run quality:fallow:commit` and `npm run quality:react-doctor:commit` before
publishing when the changed surface could affect commit hooks or code quality gates.

Release CI runs root, `appraisejs`, and `create-appraisejs` Fallow baselines independently. Existing findings are a
ratchet, not an allowance: issue counts may decrease but cannot increase, and new inline suppressions fail the source
patch guard. React Doctor remains scoped to React application source. The stable `Release check` job requires the root,
both public packages, security/quality, dependency audit, and package-content jobs.

Jobs that invoke package build or test scripts install that package's lockfile first. In particular, the
security/quality job installs `packages/appraisejs` dependencies before the MCP transport gates so package-local SDK
and schema-library versions are used instead of incompatible root dependency versions. Root CI does the same before
its aggregate build, which compiles the `appraisejs` package. It also installs Playwright's Chromium runtime before
unit validation because runtime-capsule tests execute frozen browser steps.

For major behavior, architecture, workflow, package, schema, scaffold, lifecycle, or toolchain changes, include the
current docs that describe that surface in the touched area and validation scope. If an active doc is already stale
against current source or scripts, update it before publishing even when the code change itself is small.

For swarm evolution, retain the host-conversation guidance and the final independent re-evaluation linkage alongside
the local ledger record. The ledger is Git-ignored process evidence, not approval or release authority. Static role
and sandbox configuration does not prove the effective host role or sandbox; require a host receipt or report that
evidence as unavailable.

Routing fixtures validate allowed and prohibited routes from declared signals; they do not prove that the host used a
named selector, requested model or reasoning effort, context boundary, or sandbox. Exercise those properties through
the real-host probe protocol and preserve or explicitly disclaim each receipt.
