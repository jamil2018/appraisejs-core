## Requirement hash compatibility

The browser uses WebCrypto over the existing parsed canonical requirement bytes; the server retains its existing synchronous hash API. The inherited v1 parser sorts collection values with the runtime default locale. Hash agreement across differing browser and server locales is therefore not established for all Unicode input. This repair preserves durable v1 hash semantics rather than silently rewriting existing identities.
